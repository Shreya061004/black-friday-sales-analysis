# Black Friday Sales Analysis

## Overview
Exploratory data analysis of Black Friday retail transactions to understand customer purchasing behavior and spending patterns.

## Dataset
The project uses the Black Friday sales dataset containing customer demographics, product categories, city tier, occupation, and purchase information.

## Analysis Performed
- Data cleaning and preprocessing
- Exploratory data analysis
- Customer segmentation
- Purchase behavior analysis
- Spending pattern analysis
- Analysis across age, occupation, gender, and city categories
- Identification of high-value transactions and outliers
- Data visualization using Python

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- `black-friday-sales-analysis.ipynb` — Complete analysis
- `train.csv` — Training dataset
- `test.csv` — Test dataset
